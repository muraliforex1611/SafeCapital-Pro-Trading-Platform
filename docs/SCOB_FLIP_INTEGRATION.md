## 🔍 WHAT IS SCOB? (Quick Review)

### **SCOB = Single Candle Order Block**

A **3-candle pattern** that identifies institutional entry points with precision.

**Bearish SCOB Pattern:**
```
Candle 1: Bullish (up)
Candle 2: Small candle (consolidation) ← ORDER BLOCK
Candle 3: Strong bearish (down, breaks below candle 1)

Visual:
  │  1 ↑
  │  2 →  ← SCOB Zone (entry point)
  │  3 ↓
  │    ↓
  │     ↓
```

**Bullish SCOB Pattern:**
```
Candle 1: Bearish (down)
Candle 2: Small candle (consolidation) ← ORDER BLOCK
Candle 3: Strong bullish (up, breaks above candle 1)

Visual:
  │     ↑
  │    ↑
  │  3 ↑
  │  2 →  ← SCOB Zone (entry point)
  │  1 ↓
```

**Key Rule:**
The 2nd candle (consolidation candle) is the ORDER BLOCK zone. This is where institutions placed their orders. When price returns to this zone, it's a high-probability entry.
