## SECTION 1: SCOB MASTERY - BEST PRACTICES WORLDWIDE

### 1.1 What is a SCOB (Single Candle Order Block)?

**Definition:** A Single Candle Order Block is a precise price zone marked by ONE specific candle that represents institutional order flow and provides high-probability entry opportunities.

**Why SCOB vs Regular Order Blocks?**
```
Regular Order Block:
❌ Multiple candles create wide zones
❌ Less precise entry points
❌ Higher risk (wider stop loss)
❌ Lower R/R ratios

SCOB (Single Candle):
✅ ONE candle = precise zone
✅ Exact entry price
✅ Tight stop loss (better risk)
✅ Higher R/R (1:4 to 1:5)
```

**Pattern Requirements:**

```

- Aligns with higher timeframe support

This candle proves:
- Liquidity was grabbed
- Smart money entered
- False breakdown occurred
- Reversal is beginning

CANDLE 3 (Confirmation Candle):
✅ Breaks ABOVE Candle 2's high
✅ Strong bullish close
✅ Increased volume
✅ Confirms upward momentum

This validates the SCOB!
```

## SECTION 2: FLIP CONCEPT EXCELLENCE

### 2.1 Understanding the Flip Concept

**Definition:** A "flip" occurs when a support level fails and becomes resistance (or vice versa), creating high-probability trade opportunities when price retests the flipped level.

**Core Principle:**
```
Support Breaks → Becomes Resistance (Bearish Flip)
Resistance Breaks → Becomes Support (Bullish Flip)
```

**Why Flips Work:**
- Institutional traders remember these levels
- Trapped traders exit at breakeven
- Smart money re-enters at flipped levels
- Psychological support/resistance zones
- Clear invalidation points

### 2.2 Flip Identification Criteria

#### **Bullish Flip (Support → Resistance → Support)**

```
STEP 1: Identify Original Support
- Previous swing low
- Support held multiple times
- Clear bounce history
- Institutional level

STEP 2: Support Breaks Down
- Price breaks BELOW support
- Clean break (not wicks)
- Closes below support level
- Support → Resistance transformation

STEP 3: Retest from Below
- Price comes back UP
- Tests old support (now resistance)
- Rejection occurs
- Confirms flip to resistance

STEP 4: Resistance Breaks Up (THE FLIP!)
- Price breaks ABOVE old support/resistance
- Clean break with strong candle
- Closes above level
- OLD RESISTANCE → NEW SUPPORT!

STEP 5: Retest & Entry
- Price pulls back down
- Tests flipped level
- Level holds as NEW SUPPORT
- ENTER LONG! ✅
```

#### **Bearish Flip (Resistance → Support → Resistance)**

```
STEP 1: Identify Original Resistance
- Previous swing high
- Resistance rejected multiple times
- Clear reversal history

STEP 2: Resistance Breaks Up
- Price breaks ABOVE resistance
- Clean break
- Closes above level
- Resistance → Support transformation

STEP 3: Retest from Above
- Price comes back DOWN
- Tests old resistance (now support)
- Bounce occurs
- Confirms flip to support

STEP 4: Support Breaks Down (THE FLIP!)
- Price breaks BELOW old resistance/support
- Clean break with strong candle
- Closes below level
- OLD SUPPORT → NEW RESISTANCE!

STEP 5: Retest & Entry
- Price rallies back up
- Tests flipped level
- Level holds as NEW RESISTANCE
- ENTER SHORT! ✅
```

- More precise than regular flip
- Stronger institutional significance

// 3. Gemini API Integration
async function analyzeWithGemini(chartImage, setupData) {
    const prompt = `Analyze this trading chart image for SCOB pattern quality.

    Setup details: ${JSON.stringify(setupData)}

    Assess:
    1. Visual pattern clarity
    2. Similar historical patterns
    3. Quality score
    4. Trade recommendation`;

    const response = await fetch(
        `https://generativelanguage.googleapis.com/v1beta/models/gemini-pro-vision:generateContent?key=${process.env.GEMINI_API_KEY}`,
        {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({
                contents: [{
                    parts: [
                        { text: prompt },
                        { inline_data: {
                            mime_type: 'image/png',
                            data: chartImage // base64 encoded
                        }}
                    ]
                }]
            })
        }
    );

    const data = await response.json();
    return parseGeminiResponse(data);
}

// 4. Consensus Mechanism
async function getMultiAIDecision(setupData, chartImage) {
    // Parallel execution
    const [claudeResult, gpt4Result, geminiResult] = await Promise.all([
        analyzeWithClaude(setupData),
        analyzeWithGPT4(setupData),
        analyzeWithGemini(chartImage, setupData)
    ]);

    // Vote counting
    const votes = {
        BUY: 0,
        SELL: 0,
        SKIP: 0
    };

    const results = [claudeResult, gpt4Result, geminiResult];
    results.forEach(r => votes[r.action]++);

    // Determine consensus
    const maxVotes = Math.max(...Object.values(votes));
    const consensus = Object.keys(votes).find(k => votes[k] === maxVotes);

    // Calculate weighted confidence
    const weights = {
        claude: 0.35,
        gpt4: 0.40,
        gemini: 0.25
    };

    const avgConfidence =
        (claudeResult.confidence * weights.claude +
         gpt4Result.confidence * weights.gpt4 +
         geminiResult.confidence * weights.gemini);

    return {
        decision: consensus,
        confidence: avgConfidence,
        unanimous: maxVotes === 3,
        details: {
            claude: claudeResult,
            gpt4: gpt4Result,
            gemini: geminiResult
        }
    };
}
