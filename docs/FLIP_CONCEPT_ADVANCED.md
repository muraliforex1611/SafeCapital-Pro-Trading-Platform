## 🎓 WHAT IS A FLIP CONCEPT?

### **Definition:**
A **FLIP** occurs when a price level that previously acted as **Support becomes Resistance** (or vice versa). This is one of the most powerful and reliable trading concepts in technical analysis, especially when combined with institutional order flow.

### **Why Flips Work:**
```
1. Psychological Levels:
   - Traders remember where they got stopped out
   - Institutional orders often sit at these levels
   - Price has "memory" at these zones

2. Liquidity Concentration:
   - Stop losses cluster above/below flip zones
   - Smart money hunts these stops
   - High probability of reversal at flips

3. Order Block Validation:
   - When support breaks, it becomes resistance
   - Old support = new supply zone
   - Old resistance = new demand zone

4. Market Structure:
   - Flips confirm trend changes
   - Flips validate Break of Structure (BOS)
   - Flips align with institutional behavior
```

## 📈 TYPES OF FLIPS:

### **1. Support-to-Resistance Flip (S→R)**

**Scenario:**
- Price has a support level that holds multiple times
- Support breaks down (bearish break)
- Price rallies back to broken support
- Old support now acts as resistance
- Price rejects and continues down

- ✅ Support tested 2-3 times minimum
- ✅ Clean break with strong bearish candle
- ✅ Retest with bearish rejection candle

## 🔥 BREAKER BLOCKS - ADVANCED FLIP CONCEPT:

### **What is a Breaker Block?**

A **Breaker Block** is a FAILED order block that has been "broken" and now acts in the OPPOSITE direction. This is an ADVANCED flip concept that very few traders understand.

### **Bearish Breaker Block:**

**Formation Process:**
```
Step 1: Bullish Order Block forms
   - Last bullish candle before bearish move
   - Should act as support

Step 2: Order Block FAILS
   - Price breaks BELOW the order block
   - Order block is "broken" / invalidated

Step 3: Breaker Block Activates
   - Failed order block now becomes RESISTANCE
   - Price retests from below
   - Strong rejection occurs
   - Bearish continuation

Visual:
Price
  ↑
  │  ❌ Rejection at Breaker
  │    ╱╲
  │   ╱  ╲
  │  ╱    ╲________
  │ ╱              ↘
  │╱[Bullish OB]    ↘
  │ (now Bearish     ↘
  │  Breaker Block)   ↘
  │____________________↘___→ Time
        Break
```

**Key Rules:**
1. Original order block must be valid
2. Break must be clean (not just a wick)
3. Retest should show clear rejection
4. Volume confirms the flip

**Win Rate:**
- Breaker blocks: 72-78%
- With SCOB formation: 82-88%
- With multi-timeframe: 85-90%

- Institutional memory fades

## 🧠 ADVANCED FLIP TECHNIQUES:

### **1. Liquidity Sweep + Flip Combo**

**Concept:**
Price sweeps liquidity above/below a level BEFORE flipping. This is VERY powerful because:
- Smart money grabs stops
- Retail traders get stopped out
- Then price reverses hard
- Perfect entry opportunity

**Bearish Example:**
```
Price
  ↑
  │   💥 Liquidity Sweep (fake breakout)
  │    /\
  │   /  \
  │  /____\________
  │ /    ❌ Rejection (Flip)
  │/              ↘
  │_______         ↘
  │ Support╲        ↘
  │_________╲________↘___→ Time
           Break
```

**Process:**
1. Support level established
2. Price spikes ABOVE support (liquidity grab)
3. Then breaks BELOW support (real move)

### **Step 1: Identify Potential S/R Levels**
```python
def find_support_resistance_levels(candles, lookback=50):
    """
    Find significant S/R levels in price history
    """
    levels = []

    for i in range(lookback, len(candles)):
        # Check if current level was tested multiple times
        level = candles[i].low  # or high for resistance
        touches = count_touches(candles, level, tolerance=0.0005)

        if touches >= 2:  # Minimum 2 touches
            levels.append({
                'level': level,
                'touches': touches,
                'first_touch_index': i,
                'type': 'support'  # or 'resistance'
            })

    return levels
```

### **Step 2: Detect Level Break**
```python
def detect_break(candles, level, level_type):
    """
    Detect if S/R level has been broken
    """
    for i in range(len(candles)):
        if level_type == 'support':
            # Support break = close below support
            if candles[i].close < level * 0.999:  # 0.1% buffer
                return {
                    'broken': True,
                    'break_index': i,
                    'break_candle': candles[i],
                    'volume_increase': calculate_volume_increase(candles, i)
                }

        elif level_type == 'resistance':
            # Resistance break = close above resistance
            if candles[i].close > level * 1.001:  # 0.1% buffer
                return {
                    'broken': True,
                    'break_index': i,
                    'break_candle': candles[i],
                    'volume_increase': calculate_volume_increase(candles, i)
                }

    return {'broken': False}
```

### **Step 3: Detect Retest & Flip Confirmation**
```python
def detect_flip_retest(candles, level, break_index, level_type):
    """
    Detect when price retests the broken level (flip)
    """
    for i in range(break_index + 1, len(candles)):
        if level_type == 'support':  # Now resistance after break
            # Check if price retests from below
            if candles[i].high >= level * 0.999:
                # Check for rejection
                if candles[i].close < candles[i].open:  # Bearish rejection
                    return {
                        'flip_confirmed': True,
                        'retest_index': i,
                        'rejection_candle': candles[i],
                        'time_since_break': i - break_index,
                        'volume_decrease': calculate_volume_decrease(candles, i)
                    }

        elif level_type == 'resistance':  # Now support after break
            # Check if price retests from above
            if candles[i].low <= level * 1.001:
                # Check for bounce
                if candles[i].close > candles[i].open:  # Bullish bounce
                    return {
                        'flip_confirmed': True,
                        'retest_index': i,
                        'bounce_candle': candles[i],
                        'time_since_break': i - break_index,
                        'volume_increase': calculate_volume_increase(candles, i)
                    }

    return {'flip_confirmed': False}
```

def calculate_flip_score(flip_data):
    """
    Score flip from 0-100 based on quality criteria
    """
    score = 0

    # Category 1: Level Establishment (25 points)
    touches = flip_data['level']['touches']
    if touches == 2:
        score += 10
    elif touches == 3:
        score += 18
    elif touches >= 4:
        score += 25

    # Category 2: Break Quality (25 points)
    if flip_data['break']['clean_body_break']:
        score += 10
    if flip_data['break']['strong_momentum']:
        score += 10
    if flip_data['break']['confirmation_candle']:
        score += 5

    # Category 3: Volume Analysis (20 points)
    volume_increase = flip_data['break']['volume_increase']
    if volume_increase >= 30:
        score += 10
    elif volume_increase >= 20:
        score += 5

    volume_on_retest = flip_data['retest']['volume_change']
    if volume_on_retest <= -20:  # 20% decrease
        score += 5

    if flip_data['retest']['volume_spike_on_rejection']:
        score += 5

    # Category 4: Timing (15 points)
    time_since_break = flip_data['retest']['time_since_break']
    if 5 <= time_since_break <= 20:
        score += 15
    elif 20 < time_since_break <= 50:
        score += 10
    elif 50 < time_since_break <= 100:
        score += 5

    # Category 5: Confluence (15 points)
    if flip_data['confluence']['mtf_aligned']:
        score += 5
    if flip_data['confluence']['round_number']:
        score += 3
    if flip_data['confluence']['kill_zone']:
        score += 4
    if flip_data['confluence']['liquidity_sweep']:
        score += 3

    return score
```
